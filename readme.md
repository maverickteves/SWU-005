This repository contains a backend service for a real-estate application. It is a PHP-based API project intended to support data operations for listings, appointments, inquiries, and user-related flows.

## Purpose

The codebase provides a lightweight server layer for a mobile or web client, with JSON responses and database-backed storage.

## Contents

- API endpoints for core app actions
- PostgreSQL schema and seed data
- Configuration files for database and auth settings
- OpenAPI documentation for the service contract

## Notes

This project is intended for internal or demo use and should be treated as a backend-only component. It is not a full production deployment template and should be reviewed before any real user data is connected.

## Tech stack

- PHP
- PostgreSQL
- Apache / XAMPP-compatible hosting
- JSON REST API
- PDO for database access

## Getting started

1. Set up PHP and PostgreSQL.
2. Configure the database and auth environment settings.
3. Import the schema into your PostgreSQL instance.
4. Serve the project through your web server.

## Important

This repository should not be used as-is for production-sensitive workloads without a security review, environment hardening, and proper access controls.
